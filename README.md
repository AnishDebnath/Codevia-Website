# Codevia — Technology with Purpose

A modern digital studio and technology agency web experience built with React 19, TypeScript, Tailwind CSS v4, and Vite. Crafted with high-fidelity visual aesthetics, interactive showcase components, and responsive typography.

## 🌟 Overview

**Codevia** is designed to showcase modern digital agency capabilities—transforming ambitious ideas into scalable, high-performing digital products:

- **Hero Experience**: Bold editorial headline with 3D frosted clay badges, floating interactive tags, rating badges, and featured media showcase.
- **Statistics & Metrics**: Clean data telemetry highlighting projects shaped, industries explored, and client satisfaction.
- **Interactive Services Showcase**: Dynamic carousel with keyboard arrow navigation and responsive layout.
- **Eight-Week Milestone Timeline**: Visual 8-week, 6 sign-off workflow timeline with alternating milestone cards and final launch celebration state.
- **Selected Works**: Responsive 2x2 grid featuring detailed project cards with UI mockups across web design, SaaS dashboards, and marketing landing pages.
- **Client Testimonials**: Carousel highlighting partner reviews, 5-star ratings, and client verification.
- **Interactive FAQ Accordion**: Clean questions and answers with smooth expand/collapse states and direct action CTA.
- **Hero-Style Closing CTA**: Visual bookend matching the hero container aesthetic with frosted 3D typography, floating interactive tags, and action button.
- **Contained Responsive Footer**: 4-column layout with work inquiries, navigation links, social channels, central hairline divider, and smooth Back to Top action.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. Clone or download the repository:
   ```bash
   git clone <repo-url>
   cd Codevia-Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To build the project for production:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
